# dlh-modern_ai

AI Academy - Python for ML.

## Setup

This project uses a Python virtual environment created at `.venv`.

To recreate the environment from a clean checkout:

```bash
/usr/bin/python -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r requirements.txt
```

The repository currently targets Python 3.13 and the requirements file pins the packages used by the scripts in `data_analysis/` and `machine_learning/`.
